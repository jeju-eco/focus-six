# 눈을 모아 (6호)

휴대폰용 2분 시각 탐색 게임. 5×5 격자에서 목표 도형 한 개를 찾습니다. 오답은 횟수만 기록하고 같은 문제를 다시 시도합니다. 완료 시 정답 수·오답 수·정확도를 보여줍니다. 의학적 진단 또는 실제 집중력 향상의 증거가 아닙니다.

## 실행
`python -m http.server 8786` 실행 후 브라우저에서 `http://localhost:8786/`. 첫 방문은 인터넷 연결이 필요하지만 서비스 워커 설치가 끝나면 오프라인에서 재실행할 수 있습니다. iPhone은 Safari 공유→홈 화면에 추가, Android는 Chrome 메뉴→홈 화면에 추가.

## 저장
완료한 기록 최대 100개는 사용 기기의 브라우저 localStorage에 저장합니다. 다른 기기나 브라우저로 자동 동기화되지 않으며 브라우저 데이터 삭제 시 없어집니다. 진행 중 새로고침하면 해당 판은 저장하지 않습니다. 서버로 기록을 보내지 않습니다.

## 테스트
`npm ci && npm test`. 실제 휴대폰 브라우저 호환성은 자동화와 별도로 확인해야 합니다.
