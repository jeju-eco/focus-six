# 6호 집중력 게임 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 휴대폰에서 2분 시각 탐색 게임을 플레이하고 완료 기록을 저장하는 독립 PWA.

**Architecture:** 순수 로직(core.js)과 UI/저장(app.js)을 분리한다. 정적 파일을 Pages 루트에 배포하고 서비스 워커가 셸을 캐시한다.

**Tech Stack:** Vanilla JS, CSS, Node test runner, jsdom, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-29-focus-six-design.md`

## Global Constraints

- 120초, 목표 한 개, 오답 시 같은 문제 유지.
- 완료 기록만 기기 localStorage 저장; 서버·계정 없음.
- 5호 파일/배포는 수정하지 않는다.

---

### Task 1: 게임 규칙
**Files:** `core.js`, `tests/core.test.js`, `package.json`
**Interfaces:** `FocusCore.createRound(random)` → `{target, cells, answer}`; `FocusCore.score(correct, wrong)` → 정확도 정수; `FocusCore.remaining(start, now)` → 초 정수.
- [ ] 위 함수의 한 가지 규칙씩 실패 테스트 작성 및 실패 확인.
- [ ] 최소 구현 후 해당 테스트 및 전체 테스트 실행.
- [ ] 정답 단 하나, 오답, 120초 경계 테스트.

### Task 2: 플레이 화면과 기록
**Files:** `index.html`, `styles.css`, `app.js`, `tests/ui.test.js`
**Interfaces:** 시작 버튼→타이머·격자; 칸 터치→정오답; 시간 종료→결과; `focus6.history.v1`에 완료 결과 저장.
- [ ] 실제 클릭과 시간 경과 테스트 실패 확인.
- [ ] 2분 타이머, 다음 문제, 종료, 재시작과 기록 복원 구현.
- [ ] jsdom 화면 테스트 및 실제 브라우저 터치 테스트.

### Task 3: 설치·오프라인·배포
**Files:** `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `README.md`, `tools/browser-verify.js`
**Interfaces:** 상대 경로 캐시, 홈 화면 설치 및 오프라인 재실행.
- [ ] 캐시와 manifest 유효성 확인 테스트 실패 확인.
- [ ] 서비스 워커 및 아이콘 생성, 페이지 모바일 화면 확인.
- [ ] `npm test`, 브라우저 QA, Pages 배포 및 게시 URL 파일 재조회.
